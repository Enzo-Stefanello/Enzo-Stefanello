## Projetos em destaque

### [Microsserviços — Currency Report & Currency History](https://github.com/Enzo-Stefanello/Microsservicos-DevOps)

Projeto acadêmico em equipe que utiliza Java, API Gateway, Eureka Naming Server e Docker Compose para integrar serviços relacionados à consulta de câmbio. Inclui configuração de integração contínua com GitHub Actions.

### [Simulador de Processos](https://github.com/Enzo-Stefanello/Simulador-de-Processos)

Simulador desenvolvido em C, com interpretação de instruções Assembly simplificadas, gerenciamento de processos e escalonamento EDF (Earliest Deadline First).

### [Jogo Concorrente em Go](https://github.com/Enzo-Stefanello/concurrence_game_go)

Jogo de terminal desenvolvido em Go para explorar goroutines, canais e mecanismos de sincronização na programação concorrente.
